## Architecture and findings

Core `Arc.cs` separates parsed Arc, immutable native geometry, ArcState cache and
records, shared ArcColorState, retained SkyContact and transient activity. Chart
initialization includes arc units and end+500. Kernel owns all recording; Godot
reads cache/records for segmented3D ribbon, current target and checkpoint colors.
Bridge pointer operations never manufacture a frame or input timestamp clock.
All earlier chart bytes, audio, offsets, tap/hold arbitration and pause remain.

Supported: ordinary positive2..600000ms linear `s`, `none`, `false`, colors0/1,
finite decimal normalized coordinates0..1, geometry extra0..4. Existing bounded
record/sample/index limits still apply. Timing changes inside arcs and any pair
with overlap or gap<1000ms are rejected. This excludes crossing and linked scope,
without pretending native ownership is universally exclusive. Parsed provenance
retains timing, density, source order and metadata.

```text
initialize: parse typed arcs → generate interior records → N=sum(weights)+tap/hold
            geometry base/detail vectors → shared colors → endpoint index
FRAME: update E → ranges/depth → each arc cache → retained contact spatial check
       → ordinary color acceptance → due/overdue records → per-unit recorder
       → completion/result
DOWN: allocate generated ID, retain sky/ground location, update timeline only
MOVE: previous=current; current=projected sky, no DOWN/frame/judgment
UP/CANCEL: release matching color/claimed ID using stored E; remove contact
paused FRAME: compensate wall time; clear transient activity; preserve cache/owner
```
