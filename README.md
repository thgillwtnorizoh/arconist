# Arconist

Research archive for a collaborative mobile rhythm-game reverse-engineering project.

## Purpose

Study the supplied portion of a mobile rhythm game's application to better understand mobile games generally and this game's architecture, data formats, and behavior specifically. Findings are documented with clear separation between observed evidence, inferences, and unknowns.

## Source material

- `Introduction-and-the-scheme-of-this-project.txt` — project instructions, supplied in the ChatGPT project.
- `arccopy.zip` — partial application archive, supplied in the ChatGPT project.

These source files are not included in this repository unless explicitly added later.

## Excavation workflow

For each agreed excavation task:

1. Establish the question and inspect relevant supplied files.
2. Report **Result**, **What I Found**, and **Pseudocode**.
3. Update [context.md](context.md) as the cumulative evidence-based record.
4. Add a task-specific pseudocode document under `excavations/` (or another path agreed for that task).

Previous discoveries in `context.md` should be preserved. Revise them only when a correction is justified, and record the reason. Mark uncertainty rather than presenting hypotheses as verified facts.
