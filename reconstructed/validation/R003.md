```text

    session.Frame(Godot monotonic ticks)   # existing core owns E and gameplay
    for note in core.Notes:
        pre = trunc(core.DepthAt(note.chartTime))
        current = trunc(float(pre) - core.DepthAt(core.Timeline.EffectiveTime))
        mesh.position = (425*(lane-1)-1063, 4, current) / 425

_Input keyboard:
    existing physical/logical/Unicode resolution -> session.Key -> core.Down/Up
    never insert a Frame into DOWN
_Input mouse DOWN:
    screen = (main logical mouse - viewport container origin)
             * actual subviewport size / container logical size
    rayOrigin = actual Camera3D.ProjectRayOrigin(screen)
    rayDirection = actual Camera3D.ProjectRayNormal(screen)
    reject nonfinite, outside-viewport, abs(direction.y)<1e-6
    t = -rayOrigin.y / rayDirection.y
    reject nonfinite t or t<0
    P = rayOrigin + t*rayDirection
    native = P * 425
    reject unless -500<native.z<500 and -850<=native.x<=850

    lane = X<-425 ? 2 : X<0 ? 3 : X<425 ? 4 : X==425 ? 0 : 5

    release retained pointer100 and its DOWN lane even outside the viewport

    release existing contacts and clear frontend mouse latch
```
