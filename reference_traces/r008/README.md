DOWN/UP pairs and recorder observations before R008 tests. Never generated from

with parent for drawing. Native screen640/593.0632781982422 is retained only as
native-camera metadata, not asserted equivalent to Godot pixels.

initial-input traversal, two eligible/classified contacts and one recorder.

reconstructed integration, never a new native E025 completion experiment.

Classification boundaries come from E002F/E004/E035; parent-child expiry is
E002F's parent pass, strict E>child.time+100 and parent-dependent miss guard.
Supported parent is trace mode1 only. Ordinary per-unit gauge uses existing
E006 exact-type contract (derived ArcTap is not exact LogicLongNoteBase).
No original native execution is needed or performed for these comparisons.

Supported new syntax: one interior child on linear s/none/true color0 parent;
no child on false parent, no bare true trace, no lists/multi-child/curves/effects,
no timing changes inside parents, no overlapping/linked/closely adjacent parents.
Ground taps within240ms of a child, or holds intersecting that window, reject as
unsupported conflict layouts. This conservative engineering domain avoids any
claim of generalized ground/child candidate arbitration. All prior false arcs
and old fixtures retain their original assertions/bytes.
