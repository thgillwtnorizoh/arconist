## Implementation pseudocode

```text
FRAME(wall):
    timeline.update(wall); E = R-C
    if paused: clear existing transient long-note activity; return
    previousG = G
    u = f32(f32(f32(E-camera.start)*0.5)/camera.duration)
    G = clamp(1+u,1,1.5) for supported opening direction1
    v = f32(f32(E-lanes.start)/lanes.duration)
    W = clamp(v,0,1)
    for unprocessed control with control.time < E:
        mark processed; set ONLY its transition from original event fields
    refresh retained ground primary/secondary using G/W
    existing range/cache/contact/checkpoint/expiry/completion pass

GROUND DOWN(world point, optional sky):
    reject paused/modal/invalid/duplicate physical pointer
    retain a fresh logical contact; refresh E only
    primary,secondary = native-informed selector(world,G,W)
    collect enabled notes matching EITHER lane plus eligible sky children
    existing candidate chronology / classification / once-only recorder

UP/CANCEL: remove that retained contact, existing ownership cleanup; no FRAME
PAUSE: preserve effective clock, scalars, transition/processed state and valid contacts
RESUME: final paused compensation; seek E+O and unpause; explicit modal dismissal
```
