Invalid stored clear codes normalize to missing -1; invalid snapshots/identity/schema instead produce visible non-destructive errors.

```text

```

Godot's fixed custom user-dir name `Arconist` keeps release-title/install-directory changes from silently changing the record root. A lifetime exclusive lock permits one cooperating writer. Before a write, the loaded/current file fingerprint must still match. A uniquely created same-directory temporary file is flushed to disk, then File.Replace atomically replaces the current file with a `.previous` backup (first save uses no-overwrite move). In-memory state advances only after successful commit. Corrupt/truncated/future-schema/changed files block further writes, preserve original bytes and show recovery details. No automatic reset/overwrite/retry or native I/O guarantee is inferred. Close all instances and back up the entire directory before deliberate manual recovery.
