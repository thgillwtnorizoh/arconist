## What I found and implemented

Model pause, timeline pause/P, modal active and backend paused state are distinct.
The scene tree keeps processing UI/cleanup/paused compensation; it is not presented
as Cocos Director/scheduler emulation. Ordinary steady A0 clock remains authoritative;
no audio playhead feedback. Paused frames clear hold activity only, preserving
latches, records, identities, counters, completion state and range/depth caches.
DOWN is rejected before new identity/time refresh; UP/CANCEL work while paused.
MOVE does not judge and the modal blocks gameplay pointer motion. Manual pause
retains contacts until delivered release/cancel. Focus loss deliberately revises
R005 policy to pause+CANCEL uncertain desktop contacts; focus gain never resumes.
A retained mouse is reprojected after dismissal before the next activity frame.

GameplaySession owns modal and current-run lifecycle; Resume success dismisses
routing gate, actual PausePanel hides synchronously. Negative model-only-resume
controls remain blocked, reproducing E041's functional dismissal distinction.
Escape/P/button pause; R/Resume explicitly resume; panel menu stops/unloads.

IPausableBgmBackend extends the output port without changing old fake backends or
old assertions. Godot uses StreamPaused on its single retained PCM playback.
Player-level Seek silently ignores paused audio in4.7.2. Adapter therefore locks
AudioServer, seeks the same playback, checks cursor within one22050Hz sample and
clears old resampler/interpolation samples before unpause. No Play(0), no clock
reset. Decoder position can include resampler lookahead; a separate pre-prefetch
seek readback is logged. Godot output remains an engineering substitution for
FMOD; physical latency/sample accuracy/synchronization are unverified.

Seek/unpause failure attempts to re-pause backend, preserves frozen model/timeline/
modal and allows Retry Resume or Menu. Pause/start resource failure stops/unloads
and requires a fresh run. No failed operation fabricates synchronization, changes
score or resets E. Distinct diagnostics log requests, acceptance and recovery.

```text
    R=elapsed steady ms−3000; C=R−P; E=P
    clear transient hold activity; return before judgments/expiry/completion
UP/CANCEL: remove matching retained contact; no time refresh/judgment/latch reset
RESUME (explicit, ignore duplicates):
    timeline.Update(wall) WHILE PAUSED -> C absorbs interruption
    if musicStarted:
        seek=E−B=E+O; audio.seek(seek); audio.pause(false)
        on failure: keep paused/modal; retry or menu
    clear timeline/model flags; dismiss modal/routing
    reproject truly retained mouse; next FRAME reactivates remaining contacts
PREROLL RESUME: skip seek/unpause; later strict E>−O emits the sole start request
```
