## Findings and implementation

E remains the authoritative independent C# clock. Godot playback position is never
fed into Timeline or judgments. Timeline immutable MusicStartRequest and anchored
event expose the original latch/request/store ordering. Notifications are isolated
from backend errors and reentry. All ordinary tap/hold judgment code and Chart.cs
remain unchanged. DOWN may refresh E without FRAME; UP/MOVE do not refresh time.

GameplaySession prepares the bundled stream before capturing a new monotonic clock
origin, avoiding load time consuming preroll. It snapshots AFF+selected-user O,
attaches current-run handlers and detaches old kernels. BgmController owns one
backend lifecycle; rejects nonbundled, missing, invalid, too-short and failed audio;
records logical request/attempt/acceptance separately; results/menu/replay stop and
unload. Failed cleanup blocks a new start. Observer failures cannot change time.
JudgmentsProduced snapshots events before result release clears transient arrays.

GodotBgmBackend creates one non-autoplaying non-looping AudioStreamPlayer, validates
bundled PCM16 mono22050 WAV, decodes raw bytes, Play(0), and stops/unloads/disposes.
Driver/device/mix rate/playhead/volume status and exact resource SHA are diagnostic.
Godot API acceptance is not physical audibility. No hardware latency measurement,
FMOD DSP scheduling, seek/drift correction or SFX is implemented.

Two new choices: Clockwork Steps AFF0 and identical chart AFF120. Main's explicit
user offset is integer−500..500ms, next run only, not persisted. Six earlier silent
choices/fixtures are unchanged. Original120BPM32s instrumental is CC0, synthesized
from the published integer score; no commercial songs/samples. The track has four
count-in beats; first tap2s. Five holds and35 taps comprise86 units (counts verified
in final evidence rather than assumed); chart end30120. See PLAYER.txt for exact
chart/contact instructions. No rendering judgment/counter mutation is introduced.
