## Implementation pseudocode

```text
parse group boundaries -> typed descriptors + independent timing lists
associate each tap with group and selected timing
N/end = enabled tap contributions; group lifetime = all member end +1200
initialize f32 speed/scales/bounds, integer predepth, separate group endpoint maps
FRAME:
  update one Timeline E; if paused retain frozen groups/depths and return
  each group integrates D(E)/D(E+120), calculates signed query bounds
  retained objects update using own group; no fresh depth threshold reapplied
  query own map; deduplicate active pointer; apply new-admission threshold
  expire only enabled unresolved taps; check strict whole-chart completion
DOWN:
  refresh same E without FRAME; create retained identity
  collect enabled matching active taps; existing classifier/recorder/consumed guard
UP/CANCEL: cleanup only; no judgment or new frame
replay: fresh descriptors/state/maps/timeline/contacts/results/audio session
```
